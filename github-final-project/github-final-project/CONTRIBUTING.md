# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

## How to Contribute

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Reporting Bugs

If you discover a bug, please open an issue describing:
- What happened.
- Steps to reproduce the issue.
- What you expected to happen.

## Suggesting Enhancements

If you have an idea for improving the project, open an issue explaining the proposed enhancement and its benefits.

## Submitting Changes

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Submit a pull request describing your changes.

## Code of Conduct

Please follow the project's `CODE_OF_CONDUCT` file and treat all contributors respectfully.

Thank you for helping improve this project!
