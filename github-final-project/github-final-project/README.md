# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount over a specified period at a fixed annual interest rate.

## Formula
**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal** is the initial amount.
- **Rate** is the annual rate of interest, expressed as a percentage.
- **Time** is the time period in years.

## Inputs
The calculator asks the user to enter:
1. Principal amount
2. Annual rate of interest (%)
3. Time period (years)

## Run the Calculator
Run the Bash script from a terminal:

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter the principal, annual interest rate, and time period when prompted. The script displays the calculated simple interest.

## Example
For a principal of `1000`, an annual rate of `5`, and a time period of `2` years:

`Simple Interest = (1000 × 5 × 2) / 100 = 100`
